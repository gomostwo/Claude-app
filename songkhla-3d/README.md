# สงขลา — 3D Render Video

วิดีโอ 3D แนวตั้ง (1080×1920, 30fps, 75 วินาที) ที่โมเดลและเรนเดอร์ทั้งหมดด้วย three.js (WebGL) แบบเฟรมต่อเฟรม

**ไฟล์วิดีโอ:** `songkhla-3d.mp4`

## ฉาก 3D
| เวลา | ฉาก | กล้อง |
|---|---|---|
| 0–6s | ทะเลยามพระอาทิตย์ขึ้น + นกบิน | บินเรี่ยคลื่นเข้าหาดวงอาทิตย์ |
| 6–13s | แผนที่ไดโอรามาสงขลา (หมุดหล่นลงตามสถานที่) + ตัวเลขสำคัญ | โคจรรอบโต๊ะแผนที่ |
| 13–20s | หาดสมิหลา: นางเงือกทอง (โลหะสะท้อนแสง) บนโขดหิน เกาะหนู–เกาะแมว | โคจรรอบรูปปั้น |
| 20–27s | ทะเลสาบสงขลายามเย็น + สะพานติณสูลานนท์ไฟเปิด + เรือใบ | ดอลลี่ข้างสะพาน |
| 27–34s | ถนนเมืองเก่า: ตึกชิโน-โปรตุกีส โคมแดงแกว่ง | เดินกล้องไปตามถนน |
| 34–41s | หาดใหญ่ยามค่ำ: ตึกไฟระยิบ ป้ายนีออน รถวิ่ง | เครนบินขึ้นเหนือเมือง |
| 41–48s | น้ำตกโตนงาช้าง 7 ชั้น (น้ำไหลจริง) | เครนขึ้นพร้อมโคจร |
| 48–55s | ม้าหมุนการ์ดอาหาร 3D + คอนเฟตติ | กล้องนิ่ง การ์ดหมุน |
| 55–62s | เส้นทางทริป 3 วัน วาดบนแผนที่ 3D | โคจร |
| 62–68s | เครื่องบินบินเหนือเมฆ | โคจรรอบเครื่องบิน |
| 68–75s | นางเงือกทองยามอาทิตย์ตก + ชวนมาเที่ยว | ถอยกล้องออก |

## สร้างวิดีโอใหม่
```bash
ln -sfn "$(npm root -g)/playwright" node_modules/playwright   # หรือ npm i playwright
node render.mjs frames 30                 # (แบ่งช่วงได้ด้วย --from=0 --to=19 เพื่อรันขนานกัน)
python3 music.py 75 music.wav
ffmpeg -framerate 30 -i frames/f%05d.jpg -i music.wav -c:v libx264 -pix_fmt yuv420p -crf 20 -c:a aac -b:a 160k -shortest songkhla-3d.mp4
```
ดูแบบสดได้โดยเปิด `index.html` ผ่าน http server (เช่น `npx http-server .`) ฉาก/กล้องอยู่ใน `app.js` ข้อความอยู่ใน `index.html`

three.js (MIT) อยู่ใน `vendor/`
